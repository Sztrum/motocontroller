# MotoController

Prosty panel webowy do sterowania robotem lub autkiem.

## Uruchomienie

```bash
npm install
npm run dev
```

## Sterowanie

- WASD lub strzałki,
- przyciski na ekranie,
- `STOP` po zwolnieniu klawisza lub przycisku,
- `EMERGENCY STOP` do natychmiastowego zatrzymania.

## Stack

React, TypeScript, Vite, Tailwind CSS, Vitest.

## Polecenia

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
